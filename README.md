# Phase 2 Milestone — Admin Dashboard + Contractor Web View

A production-grade admin interface and contractor portal for a logistics/construction platform. Built as the Phase 2 milestone of a 195-day full-stack engineering curriculum.

## What It Does

**Admin Dashboard**

- Data tables for orders, users, and payouts (sortable, filterable, paginated)
- Platform metrics: GMV charts, delivery stats, revenue trends
- Sidebar navigation, header, content areas
- Status indicators: badges, progress bars, toast alerts

**Contractor Web View**

- Secure TOTP generator
- Proof-of-Delivery (POD) upload
- Dispute submission form
- Responsive, accessible, professional UI

## Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Components:** shadcn/ui
- **Icons:** lucide-react
- **Charts:** Recharts
- **Deployment:** Vercel
